# sakuratetsu1004.github.io

GitHub Pages (Jekyll / minima) で動く作業メモブログ。

## 記事の追加

`_posts/YYYY-MM-DD-slug.md` を作って push するだけ。先頭に front matter を付ける:

```markdown
---
layout: post
title: "タイトル"
date: 2026-11-01 12:00:00 +0900
categories: [linux]
tags: [ubuntu, gnome]
---
```

ローカルビルドは不要（GitHub 側で自動ビルド）。
